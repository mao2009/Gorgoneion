# Security Policy

## Supported versions

**None yet.** This project is pre-alpha and not intended for production security enforcement. A supported-version policy will be published before a stable release.

## Reporting vulnerabilities

Please **do not create a public issue containing an unpatched vulnerability, working exploit, private credentials, or sensitive logs**.

Use GitHub's private vulnerability reporting mechanism for this repository **if it is enabled**. If it is not available, contact the maintainer privately using a verified contact method published on the maintainer's GitHub profile. Do not presume a response-time SLA at this stage.

Share a concise description, affected revision, impact, safe reproduction steps and mitigations without targeting systems outside your authorization.

## Defensive safety boundaries

Only test in environments you own or are explicitly permitted to assess. The project does not authorize hacking back or damaging third-party infrastructure.
